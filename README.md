# Поощрения и наказания

Три части:

| Часть | Что это | Где |
|---|---|---|
| **Сервер** | хранит счета и правила, считает деньги | `server/` (Node 18+, без зависимостей) |
| **Админка** | редактура с телефона по интернету | `https://ВАШ-САЙТ/admin` |
| **Десктоп-программа** | окно для неё (Windows/macOS) | `desktop/` (Electron) |

## Как работают деньги

- **Моментальный счёт** — сюда падает ежемесячная сумма (по умолчанию 3000, начисляется сама при первом обращении в новом месяце, пропущенные месяцы догоняются) и все бонусы. Штрафы списываются отсюда (может уходить в минус).
- **Крупно-накопительный** — копится двумя путями:
  - «крутой» бонус: на моментальный идёт сумма ×1, **плюс** на накопительный ×1.5 (`bigBonusMultiplier`);
  - она сама переводит с моментального: получает ×1.2 (`transferMultiplier`). Обратного перевода нет.
- Накопительный тратится **только на покупки от 1000** (`bigPurchaseThreshold`). Моментальный — на что угодно.
- Она может нажать «Я сделала!» — приходит заявка, вы подтверждаете или отклоняете.
- Любую операцию можно отменить из истории (баланс откатится на оба счёта).
- Всё (суммы, множители, порог, список пунктов) правится в админке → «Правила».

## Запуск сервера

```bash
npm start            # локально, порт 3000
```
При первом старте в консоли печатаются два ключа (и сохраняются в `data/keys.json`):
**её ключ** и **ваш админский**. Можно задать свои: `ADMIN_KEY=... USER_KEY=...`.

Чтобы админка открывалась с телефона из любой точки, сервер должен быть в интернете **по HTTPS**.
Самый простой путь — любой хостинг контейнеров с постоянным диском (Fly.io, Railway, Render, свой VPS):
```bash
docker build -t pnp .
docker run -d -p 3000:3000 -v pnp-data:/data -e ADMIN_KEY=ваш_пароль -e USER_KEY=её_ключ -e TZ=Europe/Moscow pnp
```
Диск `/data` обязателен — там база и ежедневные бэкапы. Часовой пояс влияет на границу месяца (`TZ`).

На телефоне: откройте `https://ВАШ-САЙТ/admin`, введите админский ключ, затем «Добавить на главный экран».

## Десктоп-программа

```bash
cd desktop
echo '{"serverUrl":"https://ВАШ-САЙТ"}' > config.json
npm install
npm start         # запустить
npm run dist      # собрать установщик в desktop/dist
```
Или без локальной сборки: GitHub → Actions → **Build desktop app** → Run workflow, указать адрес сервера, скачать `.exe`/`.dmg` из артефактов.
Если адрес не вшит, программа спросит его при первом запуске. Её ключ вводится один раз при входе и запоминается.
